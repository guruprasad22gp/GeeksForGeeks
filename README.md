# GeeksForGeeks – Problem of the Day (Java)

My Java solutions to **[GeeksforGeeks Problem of the Day](https://www.geeksforgeeks.org/problem-of-the-day)** questions, organized by month and day.

This repo is a daily practice log for sharpening my DSA skills and preparing for coding interviews.

## 📂 Repository Structure

| Folder | Month |
|--------|-------|
| [`August`](./August) | August 2026 |
| [`September_2026`](./September_2026) | September 2026 |
| [`October_2026`](./October_2026) | October 2026 |
| [`November_2026`](./November_2026) | November 2026 |

Each month folder contains that month's daily problems and my solutions.

## 🧠 Topics Covered

Arrays • Strings • Linked Lists • Stacks & Queues • Trees • Graphs • Recursion • Dynamic Programming • and more

## 🛠️ Tech Stack

- **Language:** Java
- **IDE:** Eclipse

## ▶️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/guruprasad22gp/GeeksForGeeks.git
   ```
2. Open the folder in Eclipse (or any Java IDE).
3. Open any solution file and run it.
